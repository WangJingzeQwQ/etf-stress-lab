# AI 课程设计答辩指南

## 1. 面向非金融背景听众的定位

不要用“收益很高”证明项目价值。用一句通识语言描述任务：

> 每天收盘后，模型从一组 ETF 中判断哪些更值得持有，并决定投入多少仓位。交易有手续费、流动性限制和强制平仓约束。项目比较规则、监督学习和强化学习在这些约束下是否真正有效。

项目是受限序列决策与模型评估实验，不是投资建议或实盘系统。

## 2. 四个名词

| 术语 | 答辩时的解释 |
| :--- | :--- |
| ETF | 一篮子证券的组合 |
| 杠杆 | 持仓规模超过自有资金，同时放大盈利和亏损 |
| 强平 | 账户风险达到阈值后，被系统强制卖出 |
| CVaR | 关注最差一部分情况下的平均亏损 |

100x 只是受控压力场景，不能解释为真实可获得授信。

## 3. 核心对照

| 组别 | 听众版说明 |
| :--- | :--- |
| G1 | 传统动量规则 |
| G2 | LightGBM 对 ETF 排序 |
| G3 | 加入 LSTM 时序表征后排序 |
| G4 | 排序结果 + 标准 PPO 仓位控制 |
| G6 | 排序结果 + 带尾部风险惩罚的 PPO |
| G5 | 随机决策基线 |

主线只回答三个问题：

1. 时序表征是否改善截面排序？
2. 风险敏感 PPO 是否降低极端亏损和强平风险？
3. 费用、流动性和杠杆是否改变结论？

## 4. 结果表述

可以表述：

- G3 相对 G2 的平均 Rank IC 从 `0.0974` 提高到 `0.1020`，配对置信区间支持这一增量；
- G4/G6 在预注册主比较中未表现出统计显著差异；
- 因此不能声称 CVaR 奖励整形在所有场景下有效。

不能表述：

- “AI 已经战胜市场”；
- “100x 杠杆策略可实盘使用”；
- “validation 结果等于最终收益”；
- “G4 与 G6 没有差异说明 PPO 没有价值”。

## 5. 10 分钟结构

| 时间 | 内容 |
| :---: | :--- |
| 0–1 分钟 | ETF、仓位、费用和强平约束 |
| 1–3 分钟 | 数据、H=20 标签、时间切分与无泄漏验证 |
| 3–5 分钟 | G1–G6 架构和消融关系 |
| 5–7 分钟 | Rank IC、组合收益、生存曲线和置信区间 |
| 7–9 分钟 | 负结果、失败原因和边界 |
| 9–10 分钟 | 60 秒前端回放和结论 |

## 6. 常见追问

### 为什么不是一个端到端黑盒？

为了让“选哪些 ETF”和“投入多少仓位”可以分别消融，降低小样本 PPO 同时学习选择与仓位的难度。

### 如何避免未来数据？

使用 `data_cutoff=T-1`、带 `known_at` 的公司行动、按标签重叠区间 purge 的时间切分，以及截断不变性测试。

### 为什么随机 Holdout 只能看一次？

多次观察后根据结果改阈值会构成隐性调参。一次性 claim 让最终评估保持样本外意义。

### 为什么结果不显著也算成功？

项目目标是检验预注册假设，而不是保证正向结果。能够拒绝错误假设并说明原因，是有效实验的一部分。

## 7. 现场演示

只展示：

1. 选择 G4、1x、100 万、base；
2. 运行 validation 回放；
3. 展示 K 线、时间轴、成交标记和持仓联动；
4. 打开冻结压力矩阵并解释一次。

不要把大部分时间用在 API、部署脚本或前端组件细节上。
